# Statistical and Omics Data Analysis

This repository contains selected projects completed during my Master's studies in Precision Medicine Diagnostics, focusing on statistical analysis, sequencing data analysis, transcriptomics, and metabolomics.

The projects demonstrate my experience with biological data processing, statistical testing, visualization, and interpretation using R and reproducible analysis workflows.

## Projects

### Illumina HiSeq Analysis
`IlluminaHiSeq_Phaniraj.Rmd`

Analysis of high-throughput sequencing data using R, including data processing, statistical analysis, visualization, and biological interpretation.

### Affymetrix Data Analysis
`Affymetrix_Analysis.Rmd`

Analysis of gene-expression data generated using Affymetrix platforms, including preprocessing, statistical analysis, and interpretation of expression patterns.

### Metabolomics Analysis
`Metabolomics`

Statistical exploration and analysis of metabolomics data to investigate biological variation and relationships between measured metabolites.

### Statistical Model Fitting
`Model fit.Rmd`

Application of statistical modelling approaches for analysing biological and clinical datasets.

### Sample Size Calculation
`Sample size calculation using t-test`

Estimation of required sample sizes using t-test-based statistical approaches.

### ICU Dataset
`ICUData.csv`

Dataset used for statistical analysis and model development exercises.
